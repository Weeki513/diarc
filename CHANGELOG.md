# Changelog

Each version's section is the text of its GitHub release.

## 0.1.1

- **Action menu on `⌘J`**, like the `⌘K` menu in Raycast: toggle the ASCII creatures and pick a species, switch glass,
  theme and web suggestions, edit or add tiles, sign in or out of Google and TickTick, open settings (`⌘,`). For the selected
  result: copy the link (or as Markdown), open in a new tab or window, remove from history, close or pin a tab.
- New logo: extension icon, tab icons of the Diarc, settings and Aquarium pages, settings header.
- English README and docs (Russian README: `README.ru.md`).

Install: download `diarc-0.1.1.zip` below, unzip, open `chrome://extensions` (`dia://extensions` in Dia), turn on
Developer mode → Load unpacked → pick the folder. Updating from 0.1.0: replace the folder's contents and press ↻.
For `⌘T`, use the free [Karabiner-Elements](https://karabiner-elements.pqrs.org/) with `karabiner/diarc.json`.

## 0.1.0

First public release. `⌘T` opens a command bar over the current page instead of a new tab (like Arc).
Search tabs, history, bookmarks and the web, Tab-to-search on sites, liquid glass UI, widgets (Calendar, Gmail, TickTick,
weather, links), custom widgets and ASCII creatures. Works in any Chromium browser.
